## 🚀 Featured Projects

### 🌳 [AirGrove: AI-Powered Coding IDE](https://github.com/abdulkarim20-ui/Airgrove-AI-IDE)
AI-native IDE built on Electron and Monaco with 10+ integrated tools that automate multi-step coding tasks.
- RAG-based codebase indexing with LSP and local vector stores for context-aware retrieval
- Multi-agent task planning across GPT-4o, Nemotron, and Groq-hosted LLMs, with real-time preview
- Stack: JavaScript, FastAPI, Electron, RAG

### 📚 [Ragmetry: Session-Isolated RAG System](https://github.com/abdulkarim20-ui/Ragmetry-RAG)
PDF RAG system that parses, chunks, and embeds documents into per-session ChromaDB collections.
- Answers are restricted to retrieved chunks, with a "not found in document" reply otherwise
- Multiple LLM providers behind one FastAPI backend with swappable models
- Stack: Python, FastAPI, ChromaDB, Gemini Embeddings, OpenAI, Electron

### 🗂️ [ContextPot: AI-Ready Codebase Context Exporter](https://github.com/abdulkarim20-ui/ContextPot)
Local-first desktop app that turns any repository into clean, LLM-ready Markdown context.
- Interactive project tree, 3-tier ignore engine, and automatic secret redaction
- Live background file watcher, CI on Windows and Ubuntu (Python 3.10 to 3.12)
- Stack: Python, PySide6 (Qt), GitHub Actions

### 🏗️ [AI-DDR-Agent](https://github.com/abdulkarim20-ui/AI-DDR-Agent)
Analyzes building inspection and thermal PDF reports and generates structured Detailed Defect Reports using LLMs.
- Stack: Python, LLMs

### 🔐 [DizoClip](https://github.com/abdulkarim20-ui/DizoClip)
Privacy-first Windows developer app for managing API keys, AI prompts, snippets, links, and terminal commands.
- Stack: Python
